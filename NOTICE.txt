Major changes in this fork:

- Adapted PyTorch inference and the local streaming API for short interactive
  dialog use cases.
- Added coarse timeline export from SoVITS MRTE cross-attention.
- Added prompt-side prebuilt cache loading so reference SSL/SV extraction can
  be done offline.
- Added CUDA, CPU, and DirectML backend selection.
- Added ORT DirectML GPT with GPU-resident KV and matched DXGI adapters
  and SoVITS audio decode using torch-directml.
- Added a fixed short-dialog benchmark API.
- Restored Chinese G2PW/BERT and multilingual segmentation from the optimized
  minimal-inference checkout, with bundled offline models on CPU.
- Shared the game Ami GPT across character voices, using target text without a
  GPT reference prompt while retaining each character's SoVITS voice features.
- Added runtime test scripts for CUDA, backend compatibility, and DirectML
  user performance reports.
- Replaced legacy ONNX/TensorRT paths with the dedicated ORT DirectML GPT path;
  removed WebUI, training entry points, ASR
  helpers, and runtime-unneeded language frontends from the packaging path.
